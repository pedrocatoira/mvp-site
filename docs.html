Install and find the tab

A Jira site admin installs MVP for Jira from the Atlassian Marketplace. The app works with Jira Cloud only.

Once installed, every project gets an MVP tab next to its other project views. Jira sometimes places new tabs under More at the end of the tab row. To keep MVP visible, open More and drag MVP onto the tab row. Each person pins tabs for themselves.

Create an MVP

Open the MVP tab and choose New MVP. Give it a name and choose Create. You start with five steps (Step 1 to Step 5) across the top and three lanes down the side: MVP, v1 and v2.

Everything is edited where it sits:

  • Rename the MVP, a step or a lane by clicking its title. Press Enter to save or Esc to cancel.
  • Add a step with the + after the last step. Add a lane with the bar under the lanes.
  • Remove a step or lane with its − button. Its issues move to the step before, or the lane above, and the app asks first. An MVP always keeps at least one step and one lane.
  • Reorder steps by dragging their grip left or right, and lanes by dragging up or down. The step and lane menus offer Move left, Move right, Move up and Move down for keyboard users.

Add issues

Choose Add issues. There are three ways to find issues, and you can mix them before adding:

  • JQL: type a query. Jira’s own suggestions help with fields and values, and the dialog shows how many issues match.
  • From an epic: type part of an epic’s name or key, pick it, and see its child issues.
  • By key or text: type a key such as PHX-123 or words from a summary. You can also paste several keys separated by commas.

Tick the issues you want, or use Select all, then choose Add. Issues already on the MVP are marked. Searching happens as you type, so it works on sites with any number of issues.

New issues land in the Unplaced tray above the map, so you can see exactly what still needs a place. An MVP is a hand-picked list: nothing joins it automatically later, even if it would match your query.

Arrange the map

Drag cards from the Unplaced tray onto a step and lane, between cells, or within a cell to change their order. Drag a card back to the tray to unplace it. Each card’s menu also has Move to… for keyboard users, Send back to Unplaced, and Remove from MVP. Removing an issue only takes it off this map; it never changes the issue in Jira.

Releases and fix versions

Under each lane title is a release chip. Click it to link the lane to an unreleased Jira version, or choose No release. Each release can be linked to one lane of an MVP.

When a lane is linked, the issues’ Fix version field follows the map:

You do thisFix version in Jira
Move a card into a lane linked to a releaseThat release is added. Releases linked to this MVP’s other lanes are removed. Every other fix version stays.
Move a card into a lane with no release, or back to UnplacedThis MVP’s lane releases are removed. Every other fix version stays.
Move a card to another step in the same laneNo change.
Change a lane’s release when it has issuesThe app asks whether to update those issues, or leave them as they are.

Changes are made as you, under your Jira permissions. If Jira can’t make a change (for example, you can’t edit that issue, or the issue is in a different project from the release), the card still moves and shows a warning with Jira’s reason. If someone changes a fix version directly in Jira, the card stays where it is and shows a small “doesn’t match lane” marker with a Move to matching lane action.

A Jira admin can switch this off with Sync fix version with lanes in the settings.

Track progress

  • Card colour follows the issue’s status: To Do, In Progress, In Review or Done.
  • Lane totals at the right end of each lane show issues and story points per status, plus percent done.
  • Early-start warning: if a later lane has work in progress while the first lane still has open issues, that lane is outlined in orange and a banner says how many.
  • Live updates: when anyone changes an issue in Jira, or moves something on the map, every open map updates within seconds. The dot next to Live turns grey if updates pause, and the map then refreshes every minute.

Cards

Each card shows the summary, status, epic, issue type, key, flag, story points and assignee. Click the story points to edit them in place. The expand button opens Jira’s own issue view, where you can change anything; the card updates when you close it.

Who can do what

ActionWho
View an MVP and move cardsAnyone who can browse the project
Create an MVPAnyone who can edit issues in the project (a Jira admin can limit this to project admins)
Rename, add or remove steps, lanes and issues; link releases; delete the MVPThe MVP’s creator, while they can still edit issues, and project admins
Edit story points or fix versionsWhoever Jira allows to edit that issue
Change app settingsJira admins

People never see issues that Jira hides from them. In team-managed projects with access set to Open, everyone on the site can edit issues, so everyone can create MVPs there. Use the Who can create MVPs setting to limit that.

Admin settings

Jira admins open the settings from the app’s entry in your site’s app management page (choose Configure next to MVP for Jira). Settings apply to the whole site:

  • Story points field: the field your teams estimate with, or none to hide points.
  • Status colours: which colour each Jira status uses on cards.
  • Card content: show or hide status, epic, flag, assignee and story points.
  • Early-start warning: on or off.
  • Who can create MVPs: anyone who can edit issues, or project admins only.
  • Sync fix version with lanes: on or off.
  • Delete all app data: see below.

Plans and limited mode

Every subscription includes every feature, and sites with up to 10 users subscribe for free. See pricing.

If a subscription or trial ends, nothing is deleted. The app switches to limited mode: one MVP (the most recently updated) stays editable with up to 20 issues and 3 lanes; other MVPs and extra lanes become read-only but can still be removed. Subscribing again unlocks everything as it was.

Removing data

  • Delete an MVP from its menu. This removes the map, not the issues.
  • Delete all app data on the settings page removes every MVP and the settings for the whole site, after you type DELETE to confirm. Jira issues are never touched.
  • Uninstalling the app leaves your Jira issues as they are. Atlassian removes the app’s stored data on its own schedule; see Security.

Questions

Does the app change my issues?

Only two fields, and only when you act: story points when you edit them on a card, and fix versions when cards move between lanes linked to releases (if that setting is on).

Why doesn’t a new issue appear on my MVP?

MVPs are hand-picked. Use Add issues to bring it in.

The Live dot is grey in Safari after my connection dropped.

Safari doesn’t always restore live updates after a network drop. The map keeps refreshing every minute; reload the page to get live updates back.

Can I use it with Jira Data Center?

No. MVP for Jira is built for Jira Cloud.
